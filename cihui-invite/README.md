# 慈惠道場 堂慶 邀請函（青鳥傳書）

網址：<https://tx-huang.github.io/invitation/cihui-invite/>

| 網址 | 看到什麼 |
| --- | --- |
| `.../cihui-invite/` | 通用版，信封寫「十方大德」 |
| `.../cihui-invite/?to=林小美師姐` | 信封和卷軸寫「林小美師姐」 |
| `.../cihui-invite/?host` | 產生專屬連結的工具 |

## 改內容

只改 `content.js`：日期、開始時間、地址、流程、神尊、所有文字。

## 圖

- `src/import_cihui_art.py`：從慈惠道場網站（`D:\My Code\CihuiWebsite`）拿圖：青鳥、雲、瑤池、卷軸、篆體匾額、金蓮、神尊。
- `src/ART-BRIEF.md`：請 AI 新畫的圖（信封、開場雲海、卷軸背景、祥雲、桃花、蓮池），原圖在 `src/art/`（不放上 GitHub）。
- `src/compress_art.py`：把 AI 的原圖縮小成 `art/` 的 webp：`python cihui-invite/src/compress_art.py`。
- 匾額篆體是崇羲篆體（中央研究院，CC BY-ND 3.0 TW）：原檔不改，頁尾有標示。

## 要做到的事（測試在 `tests/cihui-invite.test.mjs`）

1. 開場：雲海上，青鳥叼著一封信飛進來；一放開，信朝你飛過來、蓋滿整個畫面，變成滿版的燙金祥雲信封（約 4.8 秒，`app.js` 的 `DELIVERY_MS`），中間朱紅「慈惠」蠟封，下面貼一張紅框題簽寫名字。信到了才能點（或 Enter、空白鍵）拆；還在飛的時候點，信一到就拆。信沒拆之前後面的頁面不能操作。
2. 拆信：蠟封泛起金邊；金色祥雲從蠟封往外一路亮起來；上蓋掀開、封口的縫發光；蠟封後面湧出光、光束散開、整個信封被照成暖金色；一隻青鳥從光裡飛出去；光蓋滿畫面再淡出（5.2 秒，`app.js` 的 `OPEN_MS` 等於 `style.css` 的時間），卷軸從上往下展開。
3. `?to=名字`：信封和卷軸寫那個名字；沒有就寫「十方大德」。
4. 卷軸用國字寫日期（謹訂於國曆二〇二七年一月十六日至十七日）；下面列出兩天和星期；沒有開始時間寫「時間待公布」，有就寫「09:30 開始」。
5. 倒數到開始時間（沒有就到第一天 0 點）；過了寫「堂慶圓滿，感恩大家護持」。
6. 流程空的寫「流程待公布」；有就照天分開、照時間排。
7. 地址沒填寫「地址待公布」、不顯示地圖；有填就連到 Google 地圖。
8. 列出四位神尊，瑤池金母是主祀。
9. `?host` 不用拆信，貼上名字產生專屬連結；客人看不到這個工具。
10. 頁面有 `noindex`。
11. 頁尾標示篆體匾額的授權。
12. `style.css` 用到的每一張畫（`.art-名字`），網頁都會載入 `art/名字.webp`。
13. 「減少動態效果」時，信已經在、點一下直接看到卷軸。
