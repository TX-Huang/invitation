# 慈惠道場 堂慶 邀請函（紙雕雲開）

網址：<https://tx-huang.github.io/invitation/cihui-invite/>

| 網址 | 看到什麼 |
| --- | --- |
| `.../cihui-invite/` | 通用版，寫「十方大德」，開場是「兩者混合」 |
| `.../cihui-invite/?to=林小美師姐` | 寫「林小美師姐」 |
| `.../cihui-invite/?open=a` | 開場「雲散霧開」（`b` 金光法陣、`c` 兩者混合） |
| `.../cihui-invite/?title=開光&msg=第一行%0A第二行&sign=慈惠道場 合十` | 換掉大字、內文（一行一句）、署名 |
| `.../cihui-invite/?host` | 產生專屬連結的工具：選開場、改字、貼名字 |

## 改內容

只改 `content.js`：大字、預設開場、日期、開始時間、內文、地址、流程、神尊、所有固定的字。
給個別的人換名字、開場或邀請函上的字，不用改檔案，用 `?host` 那頁產生連結。

## 圖

- `src/ART-BRIEF.md` 第四、五批：請 AI Video 畫的紙雕雲、底紙、金箔、印泥、霧（本機 FLUX）。原圖在 `src/art/paper/`（不放上 GitHub）。
- `src/silhouettes.py`：雲的外形（給 FLUX 當參考圖，形狀我們定、質感 FLUX 畫）。
- `src/seal.py`：用印泥照片做「慈惠道場」四字白文印、蓋印的動畫格、印下面的小紙。
- `src/flake_sprites.py`：把金箔照片切成一張張小圖。
- `src/compress_art.py`：把挑好的原圖壓成 `art/` 的 webp：`python cihui-invite/src/compress_art.py`。
- `src/import_cihui_art.py`：從慈惠道場網站拿四位神尊的圖。

## 要做到的事（測試在 `tests/cihui-invite.test.mjs`）

1. 開場：左右各三層紙雕祥雲在中間交錯合起來（沒有中線），正中間一張小紙上蓋著「慈惠道場」四字朱砂印，下面寫名字和「台啟」。開場的圖載入後才開始動（網路慢最多等 3 秒）；雲合好、印蓋好（2.7 秒，`app.js` 的 `DELIVERY_MS`）才能點（或 Enter、空白鍵）打開；太早點的話，蓋好就自動打開。打開前後面的頁面不能操作。
2. 打開：印發光，印泥化成金色星光飄走。`?open=a` 雲散霧開（雲往四面飄散、融進霧裡）、`b` 金光法陣（一圈金光擴散，圈裡的雲消失）、`c` 兩者混合（預設，沒寫或寫錯都是 `c`）。開場那層在 5 秒後收掉（`app.js` 的 `OPEN_MS` 等於 `style.css` 的時間）。
3. `?to=名字`：小紙下面和邀請函都寫那個名字；沒有就寫「十方大德」。
4. 邀請函：大字預設「堂慶」，內文預設用國字寫日期加「恭請蒞臨 同霑法喜」，署名「慈惠道場 敬邀」；`?title=`、`?msg=`（一行一句）、`?sign=` 可以換。網址裡的字只當文字顯示；太長會截斷（名字 40 字、大字 6 字、內文 8 行每行 30 字、署名 20 字）。
5. 列出兩天和星期；沒有開始時間寫「時間待公布」，有就寫「09:30 開始」。
6. 倒數到開始時間（沒有就到第一天 0 點）；過了寫「堂慶圓滿，感恩大家護持」。
7. 流程空的寫「流程待公布」；有就照天分開、照時間排。
8. 地址沒填寫「地址待公布」、不顯示地圖；有填就連到 Google 地圖。
9. 列出四位神尊，瑤池金母是主祀。
10. `?host` 不用開場，可以選開場、改大字／內文／署名、貼上名字，每人一條連結（帶開場，字只有改過的才放進連結），也有一條沒有名字的通用連結；客人看不到這個工具。
11. 名字一律寫全名「慈惠道場」：頁面上不會出現單獨的「慈惠」。
12. 頁面有 `noindex`。
13. 網頁和 `style.css` 用到的每一張圖都在 `art/` 裡。
14. 「減少動態效果」時，雲已經合好，點一下直接看到邀請函。
