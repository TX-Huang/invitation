# Isaac & Dodo 婚禮邀請卡

線上網址：<https://tx-huang.github.io/invitation/idodo-invite/>

資料夾叫 `idodo`：**I do**（我願意）＋ **Dodo**，開頭的 I 也是 **I**saac。

## 網址怎麼用

| 網址 | 看到什麼 |
| --- | --- |
| `.../idodo-invite/` | 通用版，寫「親愛的朋友」，可以直接丟群組 |
| `.../idodo-invite/?to=林小美` | 寫「親愛的 林小美」 |
| `.../idodo-invite/?lang=en` | 一打開就是英文 |
| `.../idodo-invite/?host` | 產生專屬連結的工具，名字一行一個貼進去 |

## 要改內容

**只改 `content.js`**：日期、地點、我們的故事、當天流程、音樂都在裡面。
日期還沒定就填 `null`，卡片會寫「日期即將公布」，倒數會等日期定了才開始。

## 檔案

| 檔案 | 是什麼 |
| --- | --- |
| `index.html` | 網頁骨架 |
| `style.css` | 樣子和動畫 |
| `app.js` | 開信封、換名字、換語言、倒數、流程、連結工具 |
| `content.js` | 所有文字和日期地點 |
| `art/` | 網頁用的圖（壓縮過的 webp） |
| `src/art/` | AI 畫的原圖，很大，不放上 GitHub |
| `src/ART-BRIEF.md` | 給 AI 畫圖的清單 |
| `src/compress_art.py` | 把 `src/art/` 的原圖縮小成 `art/` 的 webp |

畫好的圖放進 `src/art/` 之後，在 repo 最上層跑：

```bash
python idodo-invite/src/compress_art.py
```

還沒有畫的地方，網頁會先用顏色代替，不會壞掉。

測試和 lint 在 repo 最上層跑：

```bash
npm test
```

```bash
npm run lint
```

## 這張卡要做到的事

1–11 都有自動測試（`tests/idodo-invite.test.mjs`）。12 是 CSS 管的，用瀏覽器檢查。

1. 打開網址時，先看到一個綁著緞帶的信封；點一下（或按 Enter、空白鍵）信封打開，看到邀請卡。
2. 網址有 `?to=林小美`，卡片寫「親愛的 林小美」，中文名字用圓體；英文名字用草寫體。
3. 網址沒有 `?to=`，卡片寫「親愛的朋友」。
4. 右上角可以切換中文／English，所有文字一起換，`<html lang>` 也跟著換；`?lang=en` 一打開就是英文。
5. 日期是 `null`：主卡寫「日期即將公布」，倒數區寫「日期確定後就開始倒數」。
6. 日期有填：倒數顯示還有幾天、幾小時、幾分、幾秒，每秒更新；日期過了改寫「我們結婚啦！」。
7. 當天流程照 `content.js` 的清單排出來，每一段有時間、名稱、小圖示。
8. 日期有填：流程上面有一排五天的日期，婚禮那天被愛心圈起來。
9. 地址是 `null`：不顯示「查看地圖」；地址有填：按鈕連到 Google 地圖搜尋那個地址。
10. `?host`：貼上名字（一行一個），每個名字產生一條 `?to=名字` 的專屬連結。
11. 頁面有 `noindex`，Google 搜尋找不到。
12. 系統設定「減少動態效果」時，動畫全部關掉，點信封會直接打開。
13. 信封跟參考影片一樣是直的、佔滿手機螢幕（電腦上是中間一條直的）。
14. 信封上蓋是一張有紋路的淡紫白紙，上面有一枝花和兩隻小鳥，尖端大約在畫面 44% 高；下面的油畫是信封本體。一眼看得出是信封。
15. `style.css` 用到的每一張畫（`.art-名字`），網頁都會載入 `art/名字.webp`。
16. 綁著的緞帶是一整條，中間沒有縫；解開時才分成兩段滑開。
17. 點信封先播一段真的緞帶被解開的影片（`art/untie.mp4`，第一格就是綁著的信封）；影片播完，上蓋才掀開，接著卡片升起、變成主頁。影片不能播時，改成畫出來的緞帶解開，整段開場還是至少 6.5 秒；影片卡住也會照樣打開。`app.js` 的 `OPEN_MS` 要等於 `style.css` 信封淡出結束的時間。
    影片做法：AI 用 `src/video/untie-start.jpg`（綁著）和 `untie-end.jpg`（解開）當第一格和最後一格做成影片，再跑 `python idodo-invite/src/make_untie.py` 壓成網頁用的檔案。
18. 新人名字和英文標題用英式手寫體（Pinyon Script）；中文標題用楷書手寫體；小字用襯線字，比較好讀。
